# odas_ros_msgs

Stamped SSL and SST message definitions used by the bundled ODAS ROS nodes.
This vendored interface package is built automatically with
`dracoviloc_odas`.

```bash
ros2 interface show odas_ros_msgs/msg/OdasSslArrayStamped
ros2 interface show odas_ros_msgs/msg/OdasSstArrayStamped
```
